# smart_vision_flutter

A Flutter package that simplifies AI vision integration for Flutter developers.

## Vision
Pick an image, send it to AI, and receive:
- image descriptions
- tags
- extracted text

## Status
Currently under development.

## Planned Features
- Image picking
- AI image analysis
- OCR/text extraction
- Multi-provider support (Gemini/OpenAI)
